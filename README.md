# Interferómetro — código de gráficas

Script usado para generar las figuras del informe de interferometría:

- **Actividad 1:** \(d_N\) vs \(N\) con ajuste \(b=0\) (\(d_N = mN\), \(\lambda = 2m\))
- **Actividad 3:** \(\Delta P\) vs \(N\) con ajuste \(b=0\), y \(n\) vs \(P\) con \(n = 1 + P\,\mathrm{d}n/\mathrm{d}P\)

## Uso

```bash
python3 graficas_act1_act3.py
```

Las figuras se guardan en `figuras/`.

## Dependencias

- numpy
- matplotlib
